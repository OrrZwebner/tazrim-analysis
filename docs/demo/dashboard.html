לפי ממוצע חודשי

לפי אמצעי תשלום

הסקירה תואמת לאקסל: הוצאה+הכנסה, נסכם=כן, בחלון=כן. לכל השורות (כולל העברות, כפילויות ומחוץ לחלון) — לשונית עסקאות.

איך משתמשים (3 שורות)
  1. סינון: חיפוש חופשי בכל העמודות, צ'יפים לסוג תנועה, חלון/נסכם, טווח תאריכים וסכום, ומסננים לפי עמודה. לחיצה על כותרת = מיון; "עמודות" = בחירת עמודות.
  2. שורה: לחיצה פותחת פרטי עסקה עם כל השדות, השורה המקושרת ורשימת אותו בית עסק. טבלת ציר מתחת לרשימה; "הורד CSV" = השורות המסוננות.
  3. עדכון מהאקסל: שנה בקובץ → → רענן את הדף.

מקביל ללשונית האקסל "העברות, BIT ו-PAYBOX": העברות בעו"ש, תשלומי אפליקציה ו-PAYBOX, בתוך החלון ומחוצה לו. כיוון: נכנס=זיכוי, יוצא=חיוב; הסכומים בערך מוחלט. לחיצה על כרטיס סעיף מסננת אליו.

הכנסות לפי מקור × חודש

מקור = קטגוריה (תזרים). ממוצע = סה"כ ÷ מספר החודשים; ללא אפס = ÷ חודשים עם תנועה.

לסיווג

עזרה

עסקאות — כל השורות וכל העמודות של לשונית database, מכל הסוגים.

  • סינון: חיפוש חופשי · צ'יפים לסוג תנועה · חלון (בחלון/מחוץ/הכל) · נסכם (כן/לא/הכל) · טווח תאריך עסקה · סכום מ/עד · מסננים לפי עמודה.
  • מיון: לחיצה על כותרת עמודה (לחיצה נוספת הופכת את הכיוון). ברירת מחדל: סכום יורד.
  • עמודות: כפתור עמודות — סימון/ביטול עמודות, "הצג הכל" / "ברירת מחדל".
  • פרטי עסקה: לחיצה על שורה — כל השדות, השורה המקושרת ורשימת אותו "שם מובן", וכפתורי סינון מהיר.
  • טבלת ציר: ממד שורות × ממד עמודות (חודש / אמצעי תשלום / אדם / אין) × מדד (סכום / מס' עסקאות / ממוצע); לחיצה על תא מסננת את הרשימה.
  • ייצוא: הורד CSV — השורות המסוננות, כל העמודות, UTF-8 עם BOM.

סקירה — תואמת לאקסל: הוצאה+הכנסה, נסכם=כן, בחלון=כן. פירוט קבוצה → תת-קטגוריה → בית עסק → עסקאות; KPI כולל "ממוצע חודשי ללא אפס".

העברות, BIT ו-PAYBOX — אותו סייר, מסונן כמו לשונית האקסל. הכנסות — מקור × חודש + רשימת שורות ההכנסה. לסיווג — שורות לבדיקה; הסיווג נעשה באקסל (לשונית "לסיווג ידני").

עדכון: שנה באקסל → → רענן את הדף. הגרפים דורשים את Chart.js (מהרשת או מוטמע); הטבלאות עובדות גם בלי.
